# fournitures

Demande de fournitures (lignes d'articles choisies dans le catalogue du magasin), suivi.

Logistique et administrateur : « Ajouter des fournitures » (réception, crée ou réapprovisionne les articles)
et « Liste des fournitures » (catalogue, stock, seuil d'alerte, inventaire). API : `/api/articles-stock`.

Sous-dossiers prévus : `pages/`, `components/`, `api.ts`.
